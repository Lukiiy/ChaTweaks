# ChaTweaks

A client-side Super Battle Golf [BepInEx](https://github.com/bepinex/bepinex) mod/plugin!

---

This mod adds some features to and around the chat, as well as tweaking and adding toggles for others!  

### Current features

* Allow text chat messages to persist
* A toggle for the vanilla profanity filter (Requires other clients to also toggle it off if you want to see profanity)
* Repeated messages get collapsed

### Configuration

You can configure most features in the new **ingame** settings that are available in the General tab. You can also configure the mod in the config file in `BepInEx/config/ChaTweaks.cfg`.
